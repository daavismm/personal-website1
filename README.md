# Dāvis — Personal Portfolio

A responsive one-page personal portfolio built with HTML, CSS, Tailwind CSS (CDN) and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — custom styling, responsive details and animations
- `script.js` — mobile navigation, scroll animations and contact form behavior

## Before publishing
1. The contact email is configured as `daavismm@gmail.com` in `index.html` and `script.js`.
2. Update the About, Skills, Projects and Experience content so it accurately reflects you.
3. Test the contact form. This starter form opens the visitor's email application; it does not send directly from the website. For direct form submissions, create a Formspree form and connect its endpoint.

## Preview locally
Open `index.html` in a browser. You can also use the Live Server extension in Cursor/VS Code.

## Publish with Vercel
1. Upload these files to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Keep the default settings and deploy. No build command is required for this static site.

## Publish with GitHub Pages
1. In the GitHub repository, open **Settings → Pages**.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Choose `main` and `/ (root)`, then Save.
4. Wait for GitHub Pages to provide the public URL.
